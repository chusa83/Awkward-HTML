# Contributing to awkward HTML

Bug reports, ideas and pull requests are welcome.

## How to contribute

1. Fork the repository and create a branch.
2. Make your change. Keep it focused; one fix or feature per pull request.
3. Run the tests with `cargo test`. If you changed the interface, try it with `cargo run -- example`.
4. Open a pull request that explains what changed and why.

Forking to prepare a pull request is fine. The license only forbids using the software to provide a competing product.
